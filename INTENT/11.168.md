    - **(f) THE GRADIENT: DIRECTION CONFIRMED, MAGNITUDE REFUTED, AND ONE STATISTIC SURVIVES THE AMBIENT CONTROL** [measured: Q5, Q6, Q7]. The calendar eras derived from (b) land badly on this repository: `E_learn` covers only EntityCore's first **2.5 months**, and `E_recent` holds **10 of 325 commits**. Library-only, with the commit share of each year: **2021 R = 0.1664 / median r = 0.3333 (n = 159, 48.9 %) · 2022 R = 0.1463 / 0.2857 (n = 125, 38.5 %) · 2023 R = 0.1254 / 0.1245 (n = 26, 8.0 %) · 2024 0.3738 / 0.5000 (n = 5) · 2025 0.1017 / 0.1176 (n = 3) · 2026 0.1552 / 0.1346 (n = 7)**. Across the three dense buckets — **95.4 % of all commits** — both statistics fall monotonically: **Spearman ρ = −1.000 on R and −1.000 on median r**. So the predicted DIRECTION holds. The MAGNITUDE does not: R falls by **0.041** where P2a asked for 0.10, while median r falls by **0.209**. **And the direction alone is not enough, because the whole project was declining in the same years** — scope D, `src/` over 2021 → 2023: **R 0.5257 → 0.3543 → 0.2873 (−45.3 % relative)**, against EntityCore's **0.1664 → 0.1254 (−24.6 %)**. On the line-weighted statistic the ambient tree declined MORE STEEPLY than EntityCore did, so that decline is **not attributable to EntityCore's own convergence** by this data.     - **(h) THE AGE CONFOUND, STATED WHERE IT BITES AND WHERE IT DOES NOT** [derived]. A deletion ratio measures the AGE of the code being touched as much as the mode of the work: new code is additive because there is nothing yet to delete. That confound explains (g)'s ordering in part and cannot be removed from it by this measurement — the module is one year old and the inherited tree is decades old, so (g) is *consistent with* the stratigraphy rather than proof of it, and the author-matched arms narrow the confound without eliminating it (the same author writing new code in a new directory is still writing new code). Where the confound does NOT reach is (f)'s within-EntityCore decline: over 2021 → 2023 the codebase was GROWING, so the age confound predicts R should RISE, not fall. The observed decline runs opposite to the confound's sign — which is why it is worth reporting at all, and why the ambient-trend control of (f) was the necessary second check rather than the age argument.
