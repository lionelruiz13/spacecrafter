## (b) THE PURGE WAS A PRECONDITION OF THE MERGE, NOT A FOLLOW-UP

The second tree carried `harness/sc_f24_pre` (187 187 256 B, ELF) in all 84 of its post-fork commits. Merging first would have written the blob permanently into this history and made the branch unpushable — the exact outcome §11.137 paid a rewrite to prevent — and this tree's L2 hook refuses ELF unconditionally, so the merge could not even be staged. §11.137(i1) said `purge-path.sh --repo=<path>` would take it *"when that session comes"*; it did, unchanged.

**Determinism predicted, then measured three independent ways.** (1) The 28 commits the trees share reproduced THIS tree's shas byte for byte (`d422f3f → 3003792` … `1d4f4ca → ca2a478`), so the merge base `ca2a478` is a genuine common ancestor. (3) Nine files were changed by BOTH sides and auto-merged with no conflict — `INTENT/11.133-135.md` and six `fable-dispatch/archive` entries — and every one is **byte-identical across the two trees**, because both purges computed the same map. ## (f) WHAT THE OPERATION GOT WRONG ABOUT ITSELF

- **The renumber script rewrote the OTHER side's ids in shipped source.** Run over the already-merged code repo, it changed `constellation_mgr.cpp`'s and `ModularBody.hpp`'s fix comments from §5.79/§5.81 to §5.96/§5.98 — but those belong to the tree that KEEPS 74–81. Caught by the post-run assertion, reverted, and the rule replaced by a positively-verified one: on the code side only `util/scedit/**` is this side's, established by asking which files cite those numbers at all (exactly those two, authored `04ae1d3e`/`c12ed803`). **Post-merge, an id alone no longer says whose it is; provenance does** — and that is the general form, not a slip.
- **Two substitution traps found by measuring the corpus instead of trusting the pattern.** `INTENT/11.74.md … 11.81.md` exist and their body rows start `74.` … `81.`, and §11's own stubs share that shape — an unbounded line-start renumber would have silently rewritten nine unrelated journal entries. And this corpus carries `5.75e9 km`, `5.8069e-`, `<=5.77e-17` as MEASURED VALUES — a bare-number rule would have rewritten physics as bookkeeping. Both classes verified untouched afterwards; the `§` prefix and the section bound are load-bearing, not tidiness.
- **The whole harness merge was performed first in a scratch clone pair.** The real run then had to reproduce the lab tree `8a49673b` exactly, and did — bit for bit. Every intermediate matched too (`a8e5dd95` purge tip, `b28acccf` repoint tree, `de22cc69` renumber tree, `a593b365` §5 tree). The gate is a tree hash rather than a commit hash because timestamps differ; content is what had to be identical.
