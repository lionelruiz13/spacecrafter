# INTENT §5.25

25. **`RotationElements::period` is float32 ⇒ bounded live meridian drift on fast rotators (≤~0.13°/decade measured)** — [defect, engine field-type; found by B14-periode 2026-07-23, §11.88]
    - Mechanism [observed: rotation_elements.hpp:33 + ModularBody.hpp:350]: `axisRotation = (jd−epoch)/re.period·2π + offset` with `re.period` stored float32 — the DATA value is exact (double-ideal residual ~0 measured), the live +3652 d meridian carries the float32 rounding: Iapetus 0.0002°, Proteus −0.0504°, Puck −0.0843°, Janus −0.0445°, Prometheus −0.1268° — **each == its float32 prediction to displayed precision** (predicted-from-cause, §11.88(c); not a data defect, not fitted).
    - Scope: engine-wide (all bodies, both paths — old path shares the field class), so old-new parity is unaffected; the absolute error vs IAU is what accumulates.
    - D8 status: within the as-if bar for the visual channel today (sub-pixel on these moons at any current regime); the QUERY channels (script fetch of orientation) carry it — whether that breaches D8's "no user-reachable observable" for long-simulation shows is **Vixy's call**.
    - Candidate fix (not improvised): widen the field to double (touches RotationElements ABI + both paths) — a small, mechanical change but it moves parity baselines at the ULP level; decision + timing Vixy's.
    - Cross-refs: §11.88 (finding + measurements), B14 row (vii).
