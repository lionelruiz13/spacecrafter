    - **(b) THE METHOD, stated so that "consistent" is a POSITIVE MAP.** Two halves: a mechanical FILTER that over-flags by construction, and an adjudication step that reads both texts. A clean filter run would prove nothing; what the verdict rests on is that every flag was read.

      **WHAT IS COMPARED — status-bearing content only:**
      · **S1** state declarations about the entry/row ITSELF (`OPEN`/`CLOSED`/`SUSPENDED`/`FIXED`/…), with their strike state — a `~~struck~~` state is a superseded state, not an absent one;
      · **S2** supersession/correction markers about the entry's OWN content (`SUPERSEDED`, `REFUTED`, `CORRECTED`, `RETRACTED`, `ANNOTATION`, `ADDENDUM`, strike-through);
      · **S3** authority ROUTING for this entry — what gates it, what unblocks it, which task carries its fix, which entry/commit closed it (*"fix = F39"*, *"gated on D21"*, *"rides B31's T3"*, the closing sha);
      · **S4** the date stamp attached to any of S1–S3.

      **WHAT IS DELIBERATELY NOT COMPARED — the stub is a DERIVED SUMMARY and body differences are by design (the mandate's own words):**
      · **N1** measured values, magnitudes, tables, formulas, `file:line` citations;
      · **N2** discovery provenance (*"found by the F1/B3 root-cause chain"* — who found it, not what state it is in);
      · **N3** supporting-argument citations that neither declare nor route status (e.g. §5.27's stub citing *"pre-empted by §11.113(c)"*, absent from the entry: an argument, not a status);
      · **N4** wording, ordering, level of detail, sub-item lettering, uppercase-vs-lowercase phrasing of the same fact;
      · **N5** status statements about OTHER rows carried inside an entry — those are compared at the OTHER row's own pair, never here. Without N5 every propagation-pass entry would flag every row it propagates to.

      **THE FOUR TESTS** (`intent_pair_check.py`; D and D2 are the dangerous direction, I and I2 the inverse):
      | test | direction | rule |
      |---|---|---|
      | **D** | stub → entry | every status ATOM of the stub (state word · date · `§N.M` · ledger id `A/B/D/F/T/Q/S<n>` · `SS-<n>` · backticked 7–8 hex sha) must appear somewhere in the entry file |
      | **D2** | stub → entry, structural | every `~~struck~~` span of the stub, and every dated correction-MARKER span of the stub, must be represented in the entry |
      | **I** | entry header → stub | state atoms of the entry's own header line absent from the stub |
      | **I2** | entry → stub, structural | every dated correction/annotation/addendum block INSIDE the entry whose date the stub does not carry |

      **ADJUDICATION RULES, stated because they are where the judgment lives:**
      1. The state lexicon is matched **uppercase-only**. In this ledger's grammar an uppercase state word IS a status declaration and lowercase prose is narration; a case-insensitive matcher drowns in *"the open set"*. The cost is a case-variant false-positive class (§11.99's *"root closed the same day"* against the stub's `CLOSED`, §11.122's *"NOT confirmed"* against `CONFIRMED`) — absorbed by reading, never by loosening the matcher.
      2. Class **(ii) INVERSE requires the stub to ASSERT** something the entry marks as changed. A truncated index line (*"45. S6 capability audit … […] → INTENT/11.45.md"*) cannot misstate a correction it never carried; it is N4. This single rule collapses most of the I2 volume and it is the rule that keeps the sweep from manufacturing work.
      3. Where the flag is a routing/record item present on the stub only, with the entry asserting nothing contrary, the pair is class **(i-b)** — see (d).
      4. Anything not decidable from markers + dates + cited evidence is class (iii) and is not guessed.

      **STATED COVERAGE LIMITS** (the map's edges, so the next sweep starts inside them): the bracket arm of D2/I2 caps at 300 characters, so a `[…]`-only marker longer than that is invisible to it (**16 such spans exist**); they are covered by the bold arm (no length cap) and by an additional **line-level pass with no span extraction at all** run over the whole corpus, which surfaced exactly one pair the four tests had not (§11.147, adjudicated N1). Cross-ENTRY supersession (entry X refuted by entry Y) is NOT a pair relation and is out of this sweep — measured separately in (g).
