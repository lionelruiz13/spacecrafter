# 11.148 — THE THREE "DIVERGENT" ARTIFACT SETS ARE ONE ROOT, AND EVERY GATE WAS STRUCTURALLY BLIND TO IT (2026-08-23)

148. **RE-RAN, NOT ADJUDICATED: the 67 differing artifacts trace to per-evaluation drift in the satellite position path, and no gate could ever have seen it (2026-08-23, Opus 5 (1M context), Vixy-directed; code `70dee810`, harness this entry; artifacts `b4_run3_2026-08-23`, `b24_run3_2026-08-23`, `b19_run3_2026-08-23`).**

Context and the correction that produced it. The folder merge (§11.147) left 67 artifact files differing between the two trees — `b4` 40, `b19` 21, `b24` 6 — and the merge report offered them as *"which re-run is authoritative"*, a decision. **Vixy refused the framing** [vixy 2026-08-23]: *"Before saying which re-run are authoritative, start running them all. If there is divergence, it will require to discriminate why the divergence exists, regardless. Authoritative is a derived factor, the primary one is retracing the root of divergences."* That is the correction this entry exists to record: **choosing a winner would have consumed the delta as a preference and destroyed the only signal in it.** Two runs of one measurement disagreeing is a model error, not a tie to break.

## (a) THE DISCRIMINATOR, AND WHY A THIRD RUN WAS CLEAN

The merged binary is code-equivalent to the 2026-08-09 one on every path these gates touch: `git diff 04ae1d3e HEAD -- src/` is `src/tools/translator.cpp` alone, +10/−1, locale/TUI. So run 3 tests reproducibility with the code held still. Predictions were committed to `artifacts/b4_run3_2026-08-23/PREDICTION.md` before the first launch, with the falsifier named in the file: *"if `ecl`/`dist` differ, the measurement is not reproducible, and no attribution of the 07-31 vs 08-09 delta is possible at all."*

**That prediction was FALSIFIED, which is the result.** Run 3 vs 08-09 differs in 19/122 bodies' `ecl`, 31/122 `old.ecl/dist`, 40/122 `mat`, 40/122 `screen`.

## (b) THE ROOT, MEASURED

`evalCount` — a per-body evaluation counter carried in the dump — reads **1068 (07-31) / 1061 (08-09) / 1003 (08-23)**: three runs, three values, so it is wall-clock dependent. Divergence is confined to the bodies that counter moved:

| evalCount | bodies | differing across runs |
|---|---|---|
| 0 | 32 | **0** |
| 5 | 18 | **0** |
| 10 | 1 | **0** |
| 1003 | 71 | 46 |

- **`axisRot` did NOT change** on any of the 71 [measured]. The frozen date is respected for rotation; "bodies keep spinning at `timerate 0`" is REFUTED, and it was a hypothesis worth killing early.
- **Sun-parented bodies: 0 of 20 differ** (b24). The drift is a satellite phenomenon.
- **Bounded**: max **4.1e-08 AU** absolute (Mimas), median of the nonzero set 3.2e-07 relative, max **3.3e-05** relative. All 19 are **below 0.04 float32 ULP** of the heliocentric root, so this is NOT float32 quantisation of the root position — the obvious explanation, checked and rejected.
- **Not a single clock skew either**: the implied time offset per body ranges 0.027 s (Phobos) to 0.43 s (Mimas), so one shared `dt` does not fit.
- **Ordered by how close the moon sits to its primary**: Mimas, Enceladus, Tethys, Dione, Io, Miranda … Deimos.
- **Not linear in Δ evalCount**: Δ7 → 2.28e-08, Δ58 → 4.07e-08, Δ65 → 6.35e-08. Sub-linear; the law is not established.

**Cross-confirmed in two independent instruments.** `b4` (anchor-kind gate, authored farm) and `b24` (legacy-vs-composed equivalence over the whole shipped corpus) report the **same 19 bodies, the same worst offender (Mimas), the same magnitude**. One root, reached twice by different scenes.

**What is established**: the dual_dump's satellite positions are not a pure function of (jd, data); repeated evaluation at a frozen date moves them. **What is NOT established, and is owed**: whether that path is *supposed* to be idempotent at fixed jd. No §5 row is minted here for exactly that reason — the measurement is solid, the defect claim needs a source read of the satellite position path that this session did not do. Minting a defect from a measurement whose intended behaviour is unread would be asserting more than was measured.

## (c) WHY NOBODY SAW IT — THE STRUCTURAL HALF, AND THE MORE USEFUL ONE

**Every gate here discriminates IN-RUN.** b24 compares legacy against composed in one session; b19 is a single launch; b4 compares entry 1 against entry 2. The drift is **common mode** to an in-run A/B and cancels exactly. All three gates pass on the merged binary — predicted before the runs (`PREDICTION-b19-b24.md`, Q2) and confirmed: b4 `0 failure(s)`, b24 `EQUIVALENCE HOLDS (120 bodies)`, b19 `ALL PASS`. b24's own output even names the tolerance it grants in-run: *"ecl+boundingRadius within float32 jitter on 120"*.

So the blind spot is not an oversight in any gate. It is that **the artifacts were being read as comparable records ACROSS runs, while every verification surface only ever compared WITHIN a run.** Verification-surface reachability, at the artifact layer: a green harness maps exactly its reachable comparison, and cross-run identity was never in it. The 67 files were not a conflict; they were the first time anything compared two runs.

## (d) WHAT THIS SETTLES ABOUT THE 67 FILES

**"Authoritative" is ill-posed for the accumulating fields** — none of the three runs is, and a fourth would differ again. What IS comparable, and agrees across all three: the gate verdicts, the body sets, `axisRot`, the Sun-parented bodies, and every body with evalCount 0/5/10. `--ignore-existing` kept this tree's copies during the merge; that is now recorded as arbitrary-but-harmless rather than a judgement, because for these fields there is nothing to judge.

**One thing the merge decided silently and should not have**: `b19`'s 21 differing files were resolved by git taking the second tree's TRACKED blobs — a version-control decision standing in for a measurement, the same substitution one layer up. Re-run and checked: run 3 is not byte-identical to them, but **all 8 leaf values are equal**, so the byte delta is formatting and the substitution cost nothing here. Recorded because next time it may not be free.
